# 🚀 ارزون‌جو (ArzounJoo)

> موتور هوشمند، سبک و سریع جستجو و مقایسه قیمت کالاهای بازار ایران 🇮🇷

پلتفرم **ارزون‌جو** با هدف پیدا کردن ارزان‌ترین قیمت محصولات در فروشگاه‌های معتبر آنلاین طراحی شده و مجهز به سیستم کسب درآمد (Affiliate) و لایه‌های امنیتی پیشرفته است.

---

## 🛠 تکنولوژی‌های استفاده شده
* **Python / Flask**: فریمورک قدرتمند و سبک برای راه‌اندازی سرور و وب اپلیکیشن.
* **BeautifulSoup**: برای اسکرپ و استخراج داده‌های قیمت و محصولات از وب.
* **Flask-Talisman (Helmet)**: جهت تامین امنیت هدرهای HTTP و اعمال سیاست‌های امنیتی (CSP).
* **HTML5 / CSS3 / Vazirmatn**: طراحی فرانت‌اند واکنش‌گرا و راست‌چین (RTL).
