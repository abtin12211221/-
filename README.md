# ارزون‌جو (Arzoun Joo) | موتور جستجوی هوشمند قیمت

ارزون‌جو یک وب‌اپلیکیشن مبتنی بر Flask است که به کاربران اجازه می‌دهد قیمت محصولات مختلف را در فروشگاه‌های اینترنتی جستجو و مقایسه کنند تا بتوانند ارزان‌ترین گزینه را پیدا کنند.

---

## 🚀 ویژگی‌ها و امکانات
- **طراحی مدرن و سایبرپانکی:** رابط کاربری شیشه‌ای (Glassmorphism) با گرادینت‌های نئونی و حالت Dark Mode جذاب.
- **جستجوی سریع:** قابلیت جستجوی آسان در بین محصولات مختلف.
- **طراحی ریسپانسیو:** سازگار با انواع نمایشگرها (کامپیوتر، تبلت و موبایل).
- **ری‌پازیتوری بهینه:** اجرا با استفاده از سرور پرقدرت Gunicorn.

---

## 🛠 تکنولوژی‌های استفاده شده
- **Backend:** Python, Flask, Gunicorn
- **Frontend:** HTML5, CSS3, JavaScript
- **Deployment:** Render
